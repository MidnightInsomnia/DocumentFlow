## Frontend после обновления безопасности

В исходном lock обнаружены уязвимые версии dev-зависимостей. Выполнен `npm audit fix`, после чего успешны `npm run build` и полный `npm audit`: найденных уязвимостей нет на момент проверки.

Актуальный машинный снимок — `frontend-dependency-licenses-current.json`: **137 package locations / 137 уникальных package/version**, SHA-256 окончательного lock указан внутри. Неизменённые версии наследуют проверенные tarball SRI и уведомления исходного аудита; для оставшихся новых `vite 7.3.7` и `source-map-js 1.2.2` архивы повторно скачаны и SRI проверен.

Старые frontend-тесты и прямые dev-зависимости Vitest/jsdom/testing-library удалены, поэтому прежние промежуточные итоги 203/201 больше не описывают поставку. Тесты не запускались. Полный `npm audit` после удаления: 0 найденных уязвимостей. Безопасность и лицензии — разные проверки.
